> **Unofficial SDK.** Not affiliated with, endorsed by, or officially connected to Biteship, Komerce, or any courier service.

`ongkir-sdk` adalah TypeScript SDK **multi-provider** untuk cek ongkir dan tracking pengiriman di Indonesia. Semua provider diakses lewat satu interface (`ShippingProvider`) — response selalu ternormalisasi dan error selalu dinormalisasi ke `ShippingSDKError`, apa pun bentuk asli API provider.

## Package

| Package | Deskripsi |
|---|---|
| `@ongkir-sdk/core` | Types, contract, error normalization, region resolver, contract test suite |
| `@ongkir-sdk/biteship` | Adapter Biteship — rates, tracking, webhook, shipment |
| `@ongkir-sdk/komerce` | Adapter Komerce (RajaOngkir API V2) — rates, tracking |
| `@ongkir-sdk/shipper` | Adapter Shipper (logistics v3) — rates, tracking, webhook, shipment |
| `@ongkir-sdk/cache-memory` | Wrapper caching in-memory untuk hasil `getRates()` |
| `@ongkir-sdk/hono` | Middleware Hono — expose provider sebagai REST endpoint |

## Fitur

- **Satu contract untuk semua provider** — cek ongkir, tracking, parse webhook, dan buat shipment dengan API yang sama.
- **3 provider Indonesia siap pakai** — Biteship, Komerce (RajaOngkir), dan Shipper.
- **Error ternormalisasi** (`ShippingSDKError`) — kode error konsisten lintas provider, plus flag `retryable`.
- **Bring-your-own-key** — SDK murni client-side, tidak menyimpan atau mem-proxy API key kamu.
- **Runtime-agnostic** — Node ≥18, Bun, Deno, dan Cloudflare Workers.
- **Opsional** — wrapper caching in-memory (`@ongkir-sdk/cache-memory`) dan REST middleware Hono (`@ongkir-sdk/hono`).
