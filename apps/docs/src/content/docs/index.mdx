:::note[Unofficial SDK]
Tidak berafiliasi dengan Biteship, Komerce, atau penyedia logistik mana pun. Kamu memakai API key sendiri (bring-your-own-key).
:::

`ongkir-sdk` adalah TypeScript SDK **multi-provider** untuk cek ongkir dan tracking pengiriman di Indonesia. Semua provider diakses lewat satu interface (`ShippingProvider`) — response ternormalisasi dan error dinormalisasi ke `ShippingSDKError`, apa pun bentuk asli API provider.

## Satu contract, semua provider

<CardGrid>
  <Card title="Satu contract" icon="approve-check-circle">
    `getRates`, `trackShipment`, `parseWebhook`, `createShipment` — API yang sama untuk semua provider.
  </Card>
  <Card title="Error ternormalisasi" icon="list-format">
    `ShippingSDKError` dengan kode konsisten lintas provider plus flag `retryable`.
  </Card>
  <Card title="Bring-your-own-key" icon="open-book">
    Murni client-side. SDK tidak menyimpan atau mem-proxy API key kamu.
  </Card>
  <Card title="Runtime-agnostic" icon="right-arrow">
    Node ≥18, Bun, Deno, dan Cloudflare Workers — murni Web-standard API.
  </Card>
</CardGrid>

## Package

| Package | Deskripsi |
|---|---|
| `@ongkir-sdk/core` | Types, contract, error normalization, region resolver, contract test suite |
| `@ongkir-sdk/biteship` | Adapter Biteship — rates, tracking, webhook, shipment |
| `@ongkir-sdk/komerce` | Adapter Komerce (RajaOngkir API V2) — rates, tracking |
| `@ongkir-sdk/shipper` | Adapter Shipper (logistics v3) — rates, tracking, webhook, shipment |
| `@ongkir-sdk/cache-memory` | Wrapper caching in-memory untuk hasil `getRates()` |
| `@ongkir-sdk/hono` | Middleware Hono — expose provider sebagai REST endpoint |

## Mulai dalam 3 langkah

<Steps>
1. Pasang `@ongkir-sdk/core` + adapter pilihanmu.
2. Buat instance provider dengan API key milikmu.
3. Panggil `getRates()` — hasil sudah ternormalisasi ke `RateResult[]`.
</Steps>
